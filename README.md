# paper-review

某研究生在经历多轮论文修改后，偷偷把导师的指导炼化成了一个 skill。

`paper-review` 适用于以方法设计和定量实验为主的计算机领域论文，例如数据库、数据管理和机器学习等方向。它侧重于检查论证、实验分析、呼应与冗余，并帮助建立和维护当前论文的术语、符号及比较口径，让多轮修改后的文章依然表达一致、证据清楚、前后连贯。

## 能做什么

- **梳理论证**：检查摘要、引言与结论是否呼应，区分实验观察、机制解释和因果归因，核对结论是否得到证据支持。
- **打磨实验分析**：围绕主要发现组织关键证据和解释，减少逐项复述图表，同时保留重要例外与反常结果。
- **判断呼应与冗余**：根据内容承担的论证功能决定保留、缩短或合并，避免误删必要的定义、推导和解释。
- **建立统一口径**：从当前稿件提取术语、符号、指标和比较条件，核对冲突，记录约定，并在后续修改中同步维护。
- **按需处理输出**：支持配置修订标红与打印版导出；实际处理依赖当前文档格式和可用工具。

默认关注本轮改动及其关联内容，也可按要求进行全稿复查。具体论文的名称和定义由项目自行维护，不固化在通用规则中。

## 使用方式

让支持读取 skill 文件的助手阅读 [SKILL.md](SKILL.md)，并提供稿件位置和本轮任务。例如：

> 按 paper-review/SKILL.md 检查论文实验分析部分，重点检查数字复述、机制解释和结论边界。先列出问题，不直接修改。

> 按 paper-review/SKILL.md 整理当前论文的统一口径，核对术语、符号和指标定义；无法确定的冲突集中列出供我确认。

> 按 paper-review/SKILL.md 修订本轮改动，沿用项目已有口径，并为本轮修改标红。

将示例中的路径替换为实际位置。未配置输出选项时，沿用项目已有设置；没有已有设置时，不新增标红、不额外导出打印版。
